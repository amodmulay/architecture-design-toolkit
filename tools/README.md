# Tools

Small, composable utilities used by the skills.

## Available

- [Icon Catalogue CLI](icon-catalogue/README.md): download/import SVGs, normalize, deduplicate, catalogue, and audit icon provenance.
- [Diagram Generator](diagram-generator/README.md): validate canonical architecture JSON and generate editable Draw.io XML.

Utilities should remain independent of a specific coding agent. Prefer Python 3 standard library unless a dependency materially improves reliability.
