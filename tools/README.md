# Tools

Small, composable utilities used by the skills.

## Available

- [Icon Catalogue CLI](icon-catalogue/README.md): download/import SVGs, normalize, deduplicate, catalogue, and audit icon provenance.

## Planned

- `diagram-validator/`: validate diagram source and catch common structural issues.

Utilities should remain independent of a specific coding agent. Prefer Python 3 standard library unless a dependency materially improves reliability. Document dependencies and usage.
