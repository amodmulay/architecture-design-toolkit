# Technology Selection

Help select technologies using the user's constraints, not popularity or personal preference.

## Process

1. Extract functional and non-functional requirements.
2. Identify hard constraints: existing estate, cloud/provider, skills, geography, data residency, compliance, budget, scale, latency, availability, and licensing.
3. Define evaluation criteria and weights with the user when trade-offs are material.
4. Shortlist realistic candidates; distinguish managed services from self-hosted options.
5. Compare operational burden, integration fit, maturity, ecosystem, cost model, portability, and lock-in.
6. Recommend an option and explain why alternatives were not selected.
7. State assumptions, unknowns, and what should be validated in a proof of value.

## Output

Use a concise comparison table, followed by:
- Recommended choice
- Conditions under which the recommendation changes
- Key risks and mitigations
- Validation plan

For current pricing, product capabilities, versions, or licensing, verify against current authoritative sources. Cite sources and dates. Never invent prices or benchmark results.
